# PayOps Console — backend

Generated by ApexStudio. FastAPI + SQLite, no other services required.

## Run

```bash
./run.sh   # or: uvicorn apexapp.main:app --reload --port 8000
```

Point the frontend at it by setting `VITE_API_URL=http://localhost:8000`.

## Layout

- `apexapp/main.py` — the FastAPI app; `apexapp/config.py` — settings from the environment.
- `apexapp/schema.py` — the data model (tables generated from it).
- `apexapp/api/routes/` — one router per area (auth, entities, files, events, ai,
  integrations, payments).
- `apexapp/database/` — SQLite connection + schema init (`connection.py`), seed data (`seed.py`).
- `apexapp/services/` — email sending and the real-time event broker.
- `apexapp/integrations/` — the outbound integration registry.
- `apexapp/auth.py`, `rbac.py`, `crud.py` — tokens and hashing, role guards, generic CRUD.

## What's inside

- Auth (`/api/auth/register|login|me`), pbkdf2 hashing + signed tokens.
- Role-based access control (`apexapp/rbac.py`).
- CRUD for every entity at `/api/entities/{table}`.
- File upload/download at `/api/files`.
- Real-time SSE stream at `/api/events`.
- AI proxy at `/api/ai/chat` (uses ANTHROPIC_API_KEY; simulates if unset).
- Integration proxy at `/api/integrations/{name}` (secrets from env).
- Payments at `/api/payments/checkout` (Stripe; simulates if unset).

Default admin: `admin@demo.app` / `admin` (change or remove in `apexapp/database/seed.py`).

## Postgres

The data layer lives in `apexapp/database/connection.py` + `apexapp/crud.py`. Swap the
sqlite3 calls for a Postgres driver there; the routes stay unchanged.
