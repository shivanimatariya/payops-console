# PayOps Console

Full-stack application generated by ApexStudio. You own all of it.

## Run everything

```bash
docker compose up --build
```

Frontend on http://localhost:5174, backend on http://localhost:8000.

## Structure

- `frontend/` — Vite + React + Tailwind UI.
- `backend/` — FastAPI + SQLite: auth, RBAC, CRUD, file upload, SSE.

## Run without Docker

Backend: `cd backend && ./run.sh`. Frontend: `cd frontend && VITE_API_URL=http://localhost:8000 npm run dev`.
